# Koerec - 高速音声コーパス作成ツール

合成音声制作のための音声コーパス作成を効率化するWebアプリケーションです。大量の文章を読み上げて録音し、文章と音声ファイルを対応付けたデータセットを簡単に作成できます。

## 🚀 主要機能

- **台本管理**: 事前定義台本の選択、カスタム台本のアップロード・編集
- **効率的な録音**: ワンクリック録音、リアルタイム波形表示
- **キーボードショートカット**: Space（録音）、Enter（次へ）、P（再生）
- **進捗保存**: ブラウザを閉じても進捗が保持される
- **データエクスポート**: ZIPファイル、TXTファイル形式での出力

## 📋 使用しているデータ

- **ITAコーパス**: [Unlicense](https://github.com/mmorise/ita-corpus) - 感情表現・朗読用文章
- **ROHAN4600コーパス**: [CC0-1.0](https://github.com/mmorise/rohan4600) - モーラバランス型日本語コーパス
- **オリジナルセリフ集**: 汎用的な音声モデル向けの案内・日常会話・感情表現用セリフ

## 🛠️ 技術仕様

- **フロントエンド**: HTML5, CSS3 (Tailwind), JavaScript (ES6+)
- **Web APIs**: MediaRecorder, Web Audio, IndexedDB, File API
- **対応ブラウザ**: Chrome 60+, Firefox 55+, Safari 11+, Edge 79+
- **データ保存**: ローカル保存のみ（プライバシー保護）

### 台本マニフェスト

事前定義台本は `scripts/manifest.json` の `scripts` 配列で管理します。各要素の `file` は必須で、配列の順番が画面の表示順および録音時の結合順になります。`defaultSelected` は任意の真偽値で、`true` の台本は初回表示時に選択されます。省略時は未選択です。

```json
{
  "scripts": [
    {
      "file": "音声アシスタント・操作案内.txt",
      "defaultSelected": true
    },
    {
      "file": "明るい・元気.txt"
    }
  ]
}
```

初期選択はページを開いたときだけ適用されます。カスタム台本を追加・削除してリストを再描画した場合は、ユーザーの現在の選択を維持します。

### オリジナルセリフ集

オリジナルセリフ集は、特定のキャラクターに依存しない汎用的な音声モデル向けの台本です。制作時は短いシチュエーション単位で会話の流れを設計し、収録用ファイルでは各行が単独でも意味の通る発話になるように整形します。日常会話や感情表現は、`待っていて` より `待ってて`、`何をしているの？` より `何してるの？` のような、声に出して自然な話し言葉を基本とします。操作案内、アナウンス、丁寧な会話では、用途に必要な敬語と明瞭さを保ちます。

| ファイル | 主な内容 |
| --- | --- |
| `音声アシスタント・操作案内.txt` | 確認、完了、失敗、待機、設定、通知 |
| `アナウンス・ナレーション.txt` | 館内案内、交通、天気、番組、説明 |
| `日常会話_カジュアル.txt` | 自宅、買い物、食事、外出、友人との会話 |
| `日常会話_丁寧.txt` | 仕事、初対面、依頼、確認、お礼 |
| `会話応答・相槌.txt` | 同意、否定、聞き返し、質問、短い返答 |
| `明るい・元気.txt` | 成功、再会、期待、驚き、応援 |
| `やさしい・落ち着き.txt` | 気遣い、慰め、案内、休息、就寝前 |
| `甘え・照れ.txt` | お願い、照れ、親しい相手への穏やかな甘え |
| `小声・ささやき.txt` | 秘密、静かな場所、寝かしつけ、近距離の小声 |
| `困惑・不安・悲しみ・苛立ち.txt` | 迷い、心配、落胆、抑えた怒り |

各ファイルは20行です。1行は `表示する本文,カタカナ読み` の2項形式とし、区切りには半角カンマを1個だけ使用します。本文中の読点には全角の `、` を使用します。演技指示や場面説明は本文に含めず、ファイルの分類とセリフ自体で雰囲気を表現します。

Style-BERT-VITS2形式では表示用の本文をそのまま学習テキストへ出力するため、本文だけで意図した読み方が分かる表記にします。読みが複数考えられる漢字は必要に応じてひらがなにし、英字や難しい単語は `Wi-Fi` ではなく `インターネット` のような、読みやすく自然な表現へ置き換えます。記号は発話の区切りや感情を示すために使用できます。

## 🚀 使用方法

1. ブラウザで `index.html` を開く
2. 台本を選択（複数選択可能）。初期状態では `ita_corpus_emotion`、`音声アシスタント・操作案内`、`日常会話_カジュアル` が選択済みです
3. 「録音開始」ボタンをクリック
4. 表示された文章を読み上げ、録音
5. 全文章録音完了後、データをダウンロード

開始画面には、選択中の合計行数をもとに、10行あたり約1〜3分として計算した予想録音時間を表示します。下限は録音後の確認をせずに進めた場合、上限は毎回確認した場合の目安です。分単位の端数は切り上げ、60分以上は時間と分で表示します。実際の時間は、発話の長さや録り直しの回数によって変わります。

```
├── index.html              # メインアプリケーション
├── scripts/                # 台本ファイル
│   ├── manifest.json       # 台本リスト設定

│   ├── ROHAN4600_*.txt    # ROHAN4600コーパス
│   └── *.txt                # コーパス・オリジナル台本
├── config/
│   └── export_formats.json # エクスポート形式設定
├── assets/                 # 画像リソース
├── LICENSE                 # MITライセンス
└── README.md              # このファイル
```
